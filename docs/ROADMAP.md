# DataScorpio Roadmap

This document tracks the working plan for DataScorpio.

## Foundation

- Create the initial solution and package structure.
- Define the first public API surface.
- Add focused tests for the first supported workflow.
- Add samples once the core API is stable enough to demonstrate.

## Documentation

- Expand the README with the real project purpose and installation instructions.
- Keep `docs/DataScorpio.API.md` aligned with the implemented public API.
- Record architecture decisions in `docs/ARCHITECTURE.md`.

## Release Readiness

- Confirm package metadata.
- Confirm CI build and test coverage.
- Add changelog entries before creating release branches.
- Publish through the release workflow from `releases/vX.Y.Z`.
